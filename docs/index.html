START ON YOUR MAC

Local by design.
Yours to configure.

Requires macOS and Python 3.11 or newer. Keep existing configuration when updating. The Desktop app is an ad-hoc-signed local launcher, not a notarised or self-contained distribution.

Provider accounts, local AI CLIs and third-party tools are separate installations. Real Google consent has not been exercised in the isolated tests.

python3 -m venv .runtime
cp config.example.json config.json
chmod 600 config.json
./start-u1-os.command

# Optional native launcher and Keychain helper
./macos/install-u1.sh --install
bash macos/build-keychain.sh

HONEST SCOPE

What this build does not promise.

  • 72 selected checks are not a complete accessibility, performance, security or production audit.
  • Real Google consent and live sync still need verification. Every provider retains independent accounts, capabilities and limits.
  • Managed archives are owner-only but unencrypted. Credentials, other plugin stores and unrelated Mac folders are excluded.
  • Recovery is isolated, not active rollback. The Mac launcher still needs the repository and local runtime.
  • Public quotes may be delayed. No new financial execution, account-limit merging, protected-media bypass or automatic social publishing is enabled.
  • This is a static project overview. It cannot run the backend or display your private workspace.
