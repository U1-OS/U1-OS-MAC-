START ON YOUR MAC

A local workspace.
Not a cloud account.

Requires macOS and Python 3.11 or newer. Clone the repository, create a local runtime and copy the empty example configuration. Keep existing credentials when updating.

The included macOS .app is a repository-relative launcher, not a signed standalone installer. Provider accounts and third-party tools are separate.

python3 -m venv .runtime
cp config.example.json config.json
chmod 600 config.json
./start-u1-os.command

Read the installation notes ↗

Clear boundaries, by design.

  • Public feeds can fail or be delayed. Stock widgets do not provide execution quotes or place trades.
  • Market clocks use a published calendar snapshot, not live halt monitoring. Victoria warning RSS is not an emergency-alert service.
  • Credentials and casebook files are local and access-restricted where configured, but not encrypted by these interfaces.
  • New Home widgets do not invent values. Other recovered modules still need a complete simulation, runtime and security audit.
  • Full browser and provider validation, portable native packaging, and several requested account/media workflows remain unfinished.
