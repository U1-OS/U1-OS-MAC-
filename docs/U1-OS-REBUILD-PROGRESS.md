## Privacy and operation

Drafts and the manual ledger use the existing local workspace database. Storage is
not encrypted by this interface. A draft is not an appointment until the user
reviews and approves it. Text is never interpreted as executable instructions.

The local PDF generator uses six bounded static A4 templates; no model is called.
Exports contain basic-font-compatible text and vector lines. They are not fillable
forms, and are not Canva designs or AI-generated illustrations.

Metadata exports exclude imported file contents and provider credentials. Keep
exports private. Ledger archiving retains the record in local export data.

No new recurring Codex task, automatic Git push, cloud upload, paid API request or
financial execution was created as part of the local feature installation.
