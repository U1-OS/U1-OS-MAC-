# U1 design system

Theme: **U1 VOID / BLUE**. The attached reference is a composition target only.
`design-reference.png` contains illustrative, unverified data and is never a
data source for the application.

Tokens in `u1-cinematic.css` cover ground, panels, blue/cyan/ice, semantic status,
readable text, borders, glow, radii, spacing and motion duration. The pre-existing
component tokens alias this theme during migration.

The U1 logo family is shared through the existing vector assets. Provider
identifiers use existing coloured badges; official-asset provenance for every
brand has not been completed. No logo implies an account connection.

The Home composition uses a headline/Earth hero, six actionable launch cards,
local project/storage panels and a status/activity rail. Smaller screens become
a scrolling companion layout with a collapsible navigation drawer, not a scaled
desktop screenshot. Typography and icons remain vector-based.

Keyboard focus, reduced motion, muted-by-default sound, unavailable metrics and
empty records are first-class states. Final 4K, native Mac and accessibility
coverage is tracked in the test-results document rather than assumed.
